# Frontend — Subscription Renewal Reminder

Next.js (App Router) + TypeScript + Tailwind CSS. Deployed on Netlify.

## Day 1 status

Default Next.js scaffold, cleaned up and folder structure prepared
(`components/`, `hooks/`, `lib/`, `services/`, `types/`, `tests/`). No
pages beyond the default route yet — UI work starts Day 5+.

## Development

```bash
cp .env.example .env.local
npm run dev
```

Runs at http://localhost:3000.

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run lint` — ESLint
